## Сервис управления email-рассылками
### Описание
Веб-приложение на Django для создания рассылок и отправки писем клиентам.\
Данные хранятся в PostgreSQL, письма отправляются через SMTP (Яндекс), \
для кеширования используется Redis.
### Функции
**Клиенты**: Добавление, просмотр, редактирование и удаление получателей\
**Сообщения**: Тема и текст письма\
**Рассылки**: Период отправки, получатели, сообщение, статус (Создана / Запущена / Завершена)\
**Отправка по требованию**: Кнопка на странице рассылки и команда в терминале\
**Попытки отправки**: История с датой, статусом и ответом почтового сервера\
**Главная страница**: Количество рассылок, активных рассылок и уникальных получателей\
**Регистрация и вход**: Подтверждение email по ссылке, вход, выход, восстановление пароля\
**Статистика**: Успешные и неуспешные попытки, количество отправленных сообщений\
**Роли**: Пользователь и менеджер (подробнее ниже)\
**Кеширование**: Серверное (Redis) и клиентское (заголовок ```Cache-Control```)

### Роли и права
**Пользователь**: управляет только своими клиентами, сообщениями и рассылками, \
видит статистику по своим рассылкам\
**Менеджер**: просматривает все рассылки и клиентов, просматривает список пользователей, \
блокирует пользователей, отключает рассылки.\
Чужие данные менеджер изменять и удалять не может

Менеджером становится пользователь из группы ```Менеджеры```.\
Группа создаётся командой ```python manage.py create_manager_group```,\
а пользователя в неё добавляют вручную (через админку или shell).

## Зависимости
Общие:\
django\
psycopg2-binary\
python-dotenv\
redis

Точные версии указаны в файле ```pyproject.toml```

### Для работы некоторых функций
Необходимо создать файл ```.env``` в корне проекта\
и заполнить его по шаблону: ```.env.sample```

Если ```EMAIL_BACKEND``` пустой, письма печатаются в консоль.\
Для реальной отправки указать ```django.core.mail.backends.smtp.EmailBackend```\
и пароль приложения Яндекса в ```EMAIL_HOST_PASSWORD```.

Для кеширования нужен запущенный Redis (```redis-server```).\

## Установка
Клонирование репозитория:\
```git clone https://github.com/SRUNABEGU/Project3.git```\
```cd Project3```

Установка зависимостей:\
```poetry install```

Создать базу данных PostgreSQL (например, ```mailing_service```)\
и заполнить ```.env```.

Применить миграции, создать группу менеджеров и администратора:\
```python manage.py migrate```\
```python manage.py create_manager_group```\
```python manage.py createsuperuser```

## Запуск
Запустить Redis, затем сервер:\
```redis-server```\
```python manage.py runserver```

Сайт откроется на ```http://127.0.0.1:8000/```

### Отправка рассылки из терминала
```python manage.py send_mailing <id рассылки>```

Отправка возможна только в период между началом и окончанием рассылки.
